# EduCore — School & College Platform

EduCore is a configurable school and college website and management platform designed initially for educational institutions in Bangladesh.

## Project Goals

- Provide a professional, configurable institutional website.
- Support essential administrative and academic workflows.
- Provide secure student and guardian portals.
- Support institution-specific branding and configuration.
- Maintain a reusable codebase with separate deployments and databases for each institution.
- Deliver a reliable, secure, and commercially viable product.

## Technology Direction

- **Client:** React + TypeScript
- **Server:** Node.js + Express + TypeScript
- **Database:** MongoDB + Mongoose
- **API:** REST
- **Development and deployment:** Git, Docker, automated testing, and controlled deployment

The technical stack is proposed and will be confirmed during architecture planning.

## Project Structure

- `client/` — frontend application
- `server/` — backend application
- `docs/` — requirements, workflows, and architecture documentation
- `tests/` — cross-application and end-to-end tests where appropriate

## Development Principles

1. Finalize requirements before implementation.
2. Define roles, permissions, workflows, and data relationships before designing the architecture.
3. Prioritize a manageable, sellable MVP.
4. Preserve security, data isolation, and historical record integrity.
5. Avoid unnecessary complexity and unplanned scope changes.

## Current Status

Project workspace initialized. Requirements baseline established in planning. Application development has not started.
